A one-line review of the most boring everyday object I could name — a
rubber band — written to be funny and true: the joke comes from how the
object really behaves. `main.py` (packed from `line_src.py` with
`makefun compress`) writes the review to `/output/entry.txt`.

Entry: **"The Most Boring Object, Reviewed in One Line"** — one line,
under 200 characters, concrete, specific, one twist.
